# Documentation and Sources

This folder records research references used for crop-disease, dataset, and model-development context. It is not required to run the web app.

## Quick Start

Open [sources.md](sources.md) to review the current references. When adding a disease-treatment or dataset claim, include a direct primary or authoritative source, identify the dataset/version where relevant, and check its license before relying on or redistributing its content.

## Architecture

`sources.md` is the citation index for the repository. App behavior and model limitations are documented in the root README and the READMEs in `public/` and `ml/`; citations here do not imply that a cited dataset, model, or treatment recommendation is included in the app.
